Tentang Coding Club

Coding Club SMKN 1 Subang dibentuk sebagai wadah bagi siswa Rekayasa Perangkat Lunak untuk mengembangkan kemampuan pemrograman di luar jam pelajaran sekolah. Club ini terbuka untuk semua siswa yang memiliki ketertarikan terhadap dunia teknologi dan pengembangan perangkat lunak

Melalui Coding Club, siswa dapat belajar secara praktik langsung, berbagi pengetahuan dengan sesama anggota, serta membangun portofolio proyek yang dapat digunakan sebagai bekal di dunia kerja maupun pendidikan lanjutan.

Apa yang Dipelajari

  • HTML
  • CSS
  • JavaScript
  • Pemrogramman Web
  • Git dan GitHub

Alur Mengikuti Coding Club

  1. Mengisi formulir pendaftaran
  2. Mengikuti pertemuan pertama
  3. Belajar dasar pemrogramman
  4. Membuat proyek sederhana
  5. Presentasi hasil proyek

Kegiatan Coding Club

Kegiatan 1: Belajar HMTL

Anggota mempelajari struktur HTML seperti tag, elemen, hingga cara menyusun halaman web sederhana

Kegiatan 2: Membuat Website

Anggota mempraktikan pembuatan website sederhana dengan menghubungkan HTML, CSS, dan dasar-dasar JavaScript

Kegiatan 3: Project Showcase

Anggota mempresentasikan proyek yang telah di buat
